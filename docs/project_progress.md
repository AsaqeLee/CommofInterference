│   │   ├── AM.m               # 幅度调制 ✅
│   │   └── PM.m               # 相位调制 ✅
│   ├── frequency_hopping/     # 跳频调制 ✅

### 差分编码技术突破

**DBPSK vs 传统BPSK对比**:
- **相位模糊抗性**: DBPSK完全免疫相位偏移，传统BPSK在180°偏移下误码率50%
- **载波恢复要求**: DBPSK只需频率同步，传统BPSK需要精确的相位同步
- **实现复杂度**: DBPSK增加差分编解码，但显著提高鲁棒性
- **应用场景**: DBPSK适用于相位不稳定的信道环境
